## Descripción

Este repositorio contiene cinco programas de Python que practican consultas de información mediante Programación Orientada a Objetos. Todos trabajan con objetos almacenados en listas en memoria y realizan únicamente operaciones READ: no actualizan ni eliminan registros.

- `ejercicio1.py`: búsqueda de tickets de soporte por número y listado de pendientes.
- `ejercicio2.py`: búsqueda flexible de recursos digitales por una palabra o parte del título.
- `ejercicio3.py`: filtro de componentes por tipo y stock mínimo, con identificación del mayor stock.
- `ejercicio4.py`: consultas de videojuegos por género, duración y código.
- `ejercicio5.py`: menú para consultar reparaciones por orden, estado, técnico o costo.
- `diagramas/`: diagramas de flujo correspondientes a los ejercicios 1, 3 y 5.

## Cómo ejecutar

Tener Python 3 instalado. Desde una terminal ubicada en la carpeta del proyecto, ejecutar por ejemplo:


python ejercicio1.py

s
Repetir con los demás archivos cambiando el número del ejercicio.
